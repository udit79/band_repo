A cinematic, immersive web experience for a Sufi music ensemble. This project presents a modern band landing page with atmospheric visuals, curated storytelling, a music player-inspired interface, and a polished venue/gallery experience.

## ✨ Overview

SAMA is designed as a premium digital presence for a live music act. It pairs a rich editorial layout with interactive UI patterns to create a memorable first impression for audiences discovering the band, listening to tracks, viewing live moments, and exploring upcoming shows.

This project is built with React, Vite, Tailwind-inspired styling, and a small Express server layer for production asset serving.

## 🎵 Features

- Immersive hero section with layered editorial visuals and motion effects
- Interactive music-inspired interface with track selection and playback simulation
- Event showcase for venues, cities, and upcoming appearances
- Curated gallery with lightbox navigation and smooth scrolling
- Responsive layout tuned for mobile and desktop experiences
- Theme-aware design system with reusable UI primitives
- Clean routing and error handling for a production-ready landing page

## 🛠️ Tech Stack

- React 19
- TypeScript
- Vite
- Express
- Tailwind CSS
- Radix UI primitives
- Framer Motion
- Lucide React

## 🚀 Getting Started

### Prerequisites

- Node.js 18+
- pnpm

### Install dependencies

```bash
pnpm install
```

### Run in development mode

```bash
pnpm dev
```

The app will start in development mode and serve the frontend locally.

### Build for production

```bash
pnpm build
```

### Preview production build

```bash
pnpm preview
```

### Start production server

```bash
pnpm start
```

## 🧭 Project Profile

This project is best described as an artistic brand site for a Sufi band or ensemble experience. It emphasizes emotion, atmosphere, and polished storytelling rather than a conventional SaaS dashboard or e-commerce flow.

The interface is intentionally crafted to feel like a digital magazine cover meeting a live music experience, with transitions and layers that echo a modern festival campaign.
